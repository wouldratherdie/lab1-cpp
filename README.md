Матрица: начало (Лабораторная работа №1 по ООП)



&#x20;Описание проекта

Консольная программа «Матрица», которая отрисовывает падающие линии из символов.

Вариант №24: направление движения — сверху вниз; форма линии — прямая; режим эпилепсии — случайный цвет для каждой отдельной линии.



&#x20;Стек технологий

\- Язык: C++ (стандарт C++17)

\- Среда разработки: Visual Studio 2026

\- Системные вызовы: WinAPI (работа с консолью, координаты, цвета)

\- Система контроля версий: Git + GitHub



&#x20;Функционал

\- Ввод параметров в диалоговом режиме и через CLI (matrix.exe 23 8 Y).

\- Защита от дурака: проверка диапазонов скорости (1–30) и длины (1–30), проверка Y/N.

\- Вывод справки (matrix.exe --help или matrix.exe /?).

\- Отрисовка линии с генерацией символа в начале и затиранием в конце.

\- Движение линии сверху вниз, случайная горизонтальная позиция для каждой новой линии.



&#x20;Структура классов

| Класс | Назначение |

|---|---|

| Symbol | Хранит символ, координаты, цвет; умеет рисовать и стирать себя |

| Line | Управляет набором символов; умеет «ползать» (двигаться вниз) |

| AppManager | Управляет жизненным циклом приложения, парсит аргументы, запускает диалог |

| ConsoleUtils | Служебный класс для работы с консолью (курсор, очистка, цвета) |



&#x20;Инструкция по сборке и запуску

1\. Откройте oop-matrix-lab.sln в Visual Studio 2022.

2\. Соберите решение: Build → Build Solution (или Ctrl+Shift+B).

3\. Запустите: Debug → Start Without Debugging (или Ctrl+F5).



Режимы запуска

\- Диалоговый: просто запустите matrix.exe — программа сама спросит параметры.

\- CLI: matrix.exe 23 8 Y (скорость 23, длина 8, режим эпилепсии включён).

\- Справка: matrix.exe --help или matrix.exe /?.
